# MACSE502 Programming for Data Science

Coursework and study material for MACSE502 (VIT, semester 1, Fall 2026; L-T-P-C 3-0-2-4). The course covers Python data
science libraries, Scala (collections, object-oriented programming, Breeze, Saddle) and Apache Spark basics.

This folder holds the lab work, the course documents, and three study PDFs that are generated by Python scripts.

### Coding cheat sheet

| Format | Layout | Count in the sheet |
| :-- | :-- | :-- |
| Task table | `T.No \| Task Desc \| Program code` | 193 rows for lab programs 1 to 25 (Python 1 to 17, Scala 18 to 25) |
| Debug the program | `S.No \| code \| description` | 88 bugs (62 Python, 26 Scala) with the real error messages |

## Rebuilding the PDFs

The scripts were written and run on Windows with PowerShell. There is no `requirements.txt`.

**Python 3.10** with `reportlab`, `pygments`, `matplotlib` and `pillow` is enough to build the PDFs from the stored content and
outputs:

```powershell
cd Question_Bank
python build_pdf.py                         # question bank
python build_notes.py                       # topic notes
python cheatsheet\build_cheatsheet.py       # coding cheat sheet
python cheatsheet\build_gap.py              # syllabus gap code
```

Re-running the code behind them needs more packages. Versions used for the cheat sheet: pandas 2.3.3, NumPy 1.26.4,
scikit-learn 1.7.2, Plotly 7.1.0, Bokeh 3.9.2, seaborn 0.13.2, matplotlib 3.10.0, Beautiful Soup 4.15.0, statsmodels 0.14.4,
PyMuPDF (`fitz`). The question-bank demos also use nltk, folium, selenium, scrapy, ChatterBot with spaCy, and
xgboost, torch, tensorflow and keras for `n2_dl.py`.

**Scala** programs run with [scala-cli](https://scala-cli.virtuslab.org/) (Scala 2.13.12, Java 17). Library versions:
Breeze 2.1.0, Spire 0.18.0, Plotly.Scala 0.8.5, and the Saddle fork `io.github.pityka::saddle-core:4.0.0-M14`. The original
Saddle and Vegas do not resolve for Scala 2.13.

Re-running the checks (from `Question_Bank/cheatsheet`):

| Script | Checks |
| :-- | :-- |
| `verify_py.py` | Every Python task-table row, in order |
| `verify_scala.py` | The five Scala task tables (compile and run) |
| `verify_py_debug.py`, `verify_debug_scala.py` | Each buggy snippet and its fix; they write `debug_*_results.json` |
| `verify_fill.py` | The 13 complete missing-code programs; writes `fill_results.json` |
| `verify_gap_py.py` | Every Python row of the gap file, one empty folder per table; writes `gap_py_results.json` |
| `verify_gap_scala.py` | The 8 Scala programs of the gap file, plus the REPL transcript; writes `gap_scala_results.json` |

The gap file needs more libraries than the cheat sheet: SciPy, NLTK, Folium, requests, Scrapy, ChatterBot with the spaCy model
`en_core_web_sm`, XGBoost, TensorFlow with Keras, PyTorch (CPU), and Spark 3.5.1 (scala-cli downloads Spark itself).
`verify_gap_py.py` runs four virtualenvs (`venv`, `venv_cb`, `venv_sc`, `venv_dl`) that it expects in `%TEMP%\pds`, because
ChatterBot, Scrapy and the deep-learning libraries do not share one environment here. The REST rows run against the local
stub server in `gap_stub.py`, and the Scrapy spider against two local HTML files.

Paths you may have to change on another machine:

- `Question_Bank/run_and_capture.py`, `verify_scala.py`, `verify_debug_scala.py` and `verify_gap_scala.py` expect scala-cli at
  `%TEMP%\pds\scala\scala-cli.exe`. `verify_gap_py.py` also expects NLTK data in `%TEMP%\pds\nltk_data`.
- `Question_Bank/cheatsheet/parse_submissions.py` reads the lab records from an absolute path stored in its `SUBS` variable.

## What git ignores

See [`.gitignore`](.gitignore). The main rules:

- `books/` and `*.zip`: copyrighted books, about 100 MB.
- `Prac/Submitions/`: the lab records carry the student's name and registration number. Delete that line from
  `.gitignore` if you want them in the repository.
- Generated files: `__pycache__/`, `.scala-build/`, `.bsp/`, `.bloop/`, `*.log`, `*.sqlite3`, and the stray `out_*.html`
  in the root.

The three PDFs, `Question_Bank/outputs/` and `programs.json` stay tracked because the builders read from them.
